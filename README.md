У цьому проєкті зібрані завдання з теми функцій вищого порядку в JavaScript. Реалізації показують, як працюють колбеки, методи масивів і передавання функцій як аргументів. Основу складають приклади з використанням map, filter, reduce та власних функцій, що оперують іншими функціями. Матеріал структурований так, щоб можна було швидко переглянути рішення, розібратися в логіці та використати їх як основу для подальших робіт або перевірки викладачем.
